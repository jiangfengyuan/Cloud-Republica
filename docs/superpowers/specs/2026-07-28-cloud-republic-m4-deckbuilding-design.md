## 1. 目标与非目标

**目标**
- 真实牌库机制：每局有抽牌堆/弃牌堆/手牌三态，抽牌改为**无放回取样**，抽空后弃牌堆重洗——替代现状的 66 张全表均匀有放回抽样。
- 局前构筑：开始界面「牌库」入口进入构筑编辑器，玩家从 66 张卡池中组自定义牌库并持久化。
- 默认牌库 = 全部 66 张（「全域牌库」）：22 回合游戏抽牌 ~48 张 < 66，概率分布与现状几乎等价——**非构筑玩家体验与平衡基本不变**，构筑是深度选项而非门槛。

**非目标**
- 不做派系专属牌池/派系锁卡（派系保持规则修正器定位，构筑是另一条自定义轴）
- 不加新卡牌、不改既有 66 卡任何字段
- 不做牌库分享/导入导出、不做多牌库存档槽（单一当前牌库 + 全域默认）
- 不动胜利条件、不动 M1/M2/M3 已裁决事项

## 2. 牌库规则

### 2.1 局内三态（js/state.js + js/engine.js）

- state 新增：`drawPile[]`（洗牌后的卡 id 数组）、`discardPile[]`、`deckId`（'full' 或 'custom'）
- 手牌元素从 `{...card, uid}` 不变；**出牌路由**：
  - permanent 卡打出 → 装入 state.permanentCards（既有行为），**不进弃牌堆**（已安装，防无限复制循环）
  - contract 卡打出 → 进 discardPile
  - 回合结束手牌**保留不弃**（维持现状手牌管理压力，handLimit 8 仍是约束）
- drawCard 改为：drawPile 空 → discardPile 重洗入 drawPile（经 engine.rng 洗牌，保持可注入随机源）；两堆皆空 → 抽不到（log 既有键或新增 log.deck_empty）
- guaranteedCards 开局预发仍走「从牌库取出」语义（从 drawPile 移除对应 id 一张，保证不重复抽到超过牌库含量的卡）

### 2.2 构筑约束（js/data.js 新增 DECK_RULES）

| 规则 | 值 |
|---|---|
| 自定义牌库最小/最大 | 20 / 40 张 |
| 单卡最大 copies | 2 |
| 默认牌库 | 'full' = 全 66 张 ×1 |
| 持久化 | cr_deck v1：`{ v:1, deckId:'full'\|'custom', cards:{ [cardId]: 1\|2 } }` |

非法配置加载时逐条剔除（未知 id、超 copies、总数越界）→ 全废则回退 'full'。

### 2.3 构筑编辑器 UI（新全屏屏，复用 .end-screen 层模式）

- 开始界面 header-controls 加「牌库」按钮（图标 + 当前牌库名/张数）
- 编辑器布局：左 = 卡池（66 张，按类别分组，每张显示已有 copies 圆点 +/− 按钮）；右/顶 = 当前牌库摘要（总张数、类别分布条、每张列表、清空/恢复全域按钮）
- 约束实时执行：满 40 加号置灰、单卡 2 张后加号置灰、<20 张时「完成」置灰并提示
- 卡面复用 cardArt + ICONS（编辑器单卡 DOM 预算：池 66 行 + 库 ≤40 行，用紧凑行式而非全卡面，控制节点数）
- 变更即写 cr_deck；语言切换全量重渲染
- design 约束：复用 .btn/glass/令牌/图标体系；不自创配色；信息层级 = 池（浏览）次级、库（决策）主级

### 2.4 对局内展示

- 资源面板或手牌区加一行小字：抽牌堆 N · 弃牌堆 M（图标 + 数字，灰色次要信息）
- 结算屏记录本局牌库（deckId + 张数），cr_stats 不动 schema（牌库维度战绩留 M5+ backlog）

## 3. 平衡与模拟器

### 3.1 预期影响

默认全域牌库下：无放回取样 vs 现状有放回——22 回合内重复率略降，净化引擎卡（12/49）期望可得性略升，胜率可能小幅上移。**全部区间重标定**（用 --calibrate 跑全矩阵后重新 pin）。

### 3.2 模拟器扩展（test/simulate.js）

- freshState/playGame 支持 deck 配置透传；AI 打分逻辑不变
- 断言矩阵：
  1. 全域默认 × 既有全矩阵（三档基线 + 三派系 + 满配 meta + 沙盒三预设）：全部重标定重 pin
  2. 牌库机制单测：无放回性（抽 N 张不重复直至牌库空）、重洗正确性（弃牌回抽牌堆）、permanent 不入弃牌、guaranteedCards 从牌库移除
  3. 自定义牌库冒烟：2-3 个典型构筑（经济流/净化流/最小 20 张）× medium 各 500 局，0 崩溃 + 胜率 pin
  4. 非法构筑钳制用例
- **covenant 警示**（M3 backlog）：pin 余量仅 2.2pp，本轮重标定后重 pin 并在 globals 记录新余量

## 6. 风险与对策

- **平衡全面漂移**：全域默认 ≈ 现状（无放回 48/66 抽样），预期偏差小；--calibrate 重标定 + 全部区间重 pin，covenant 余量单独复核
- **编辑器 DOM 爆炸**：编辑器懒渲染 + 行式紧凑布局；66+40 行 × ~6 节点 ≈ 640 节点只在编辑器屏存在，不进首屏
- **状态兼容**：cr_deck 损坏/非法全回退 'full'；simulate.js 不传 deck 参 = 全域，既有调用兼容
- **洗牌随机源**：一律走 engine.rng 注入（Fisher-Yates），模拟器 seed 可复现
