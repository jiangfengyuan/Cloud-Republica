# Cloud Republic 重构路线

| 阶段 | 状态 | 退出条件 |
|---|---|---|
| 0. 冻结基线 | 已完成 | 规则、旧存档、桌面/移动视觉基线齐全 |
| 1. 新骨架 | 已建立 | 类型检查、单元测试、离线构建全部通过 |
| 2. 领域内核 | 进行中 | 完整结算、抽牌、洗回与三组种子回放已一致；继续迁移卡牌命令 |

| 5. 视觉与动效 | 已建立基线 | 桌面、移动、键盘、减少动效基线通过；待统一 token 与高对比测试 |
| 6. 切换清理 | 未开始 | 新架构全量接管，旧脚本和覆盖式 CSS 可删除 |

## 切换规则

1. 每次只迁移一个可独立验证的命令或页面。
2. 新旧实现必须消费同一输入，并比较状态摘要、日志 key 和随机数状态。
3. 切换后仍保留一轮旧实现对照；差异必须明确登记为预期变更。
4. 任何存档、胜率或无障碍回归都会阻止下一阶段切换。
